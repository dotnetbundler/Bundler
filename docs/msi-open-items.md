# MSI 外部输入与验收待办

当前 MSI 后端**尚未实现**，下表是将来各阶段需要准备的外部环境和证据，不是已实现功能的剩余验收。自动化可覆盖的部分必须在对应阶段新增测试，人工步骤见 `docs/msi-manual-testing.md`。

| ID | 最早阶段 | 所需输入/环境 | 完成证据 |
| --- | --- | --- | --- |
| MSI-OI-01 | MSI-1 | 官方 WiX 3.14.1 归档、实际 SHA-256、全部捆绑文件许可证、体积测量 | 来源、哈希、许可清单、包增量、断网编译结果 |
| MSI-OI-02 | MSI-1 | 干净 Windows x64 与 ARM64 宿主，Framework 基线 | 工具启动/编译日志、OS build、预装依赖、失败边界 |
| MSI-OI-03 | MSI-1 | 隔离 Windows VM/CI | 真实安装与卸载烟雾测试、verbose log、状态/清理断言 |
| MSI-OI-04 | MSI-2 | 标准用户和管理员账户，Windows UAC/策略差异 | current user/per machine 的权限与目录/注册表证据 |
| MSI-OI-05 | MSI-2 | 真实旧发行包或受控两版本发行包 | major upgrade、降级拒绝、资源归属和用户数据证据 |
| MSI-OI-06 | MSI-3 | 生产证书与时间戳设施 | 链、时间戳、签名验证；私钥不入库 |
| MSI-OI-07 | MSI-3 | 可抛弃的重启/锁定文件/损坏包 VM | 3010 或明确失败码、重启后状态、回滚日志 |
| MSI-OI-08 | MSI-4 | Windows 10/11 x64、ARM64 支持矩阵 | 每组合的构建、安装、升级、修复、卸载记录；未测组合限定支持声明 |
| MSI-OI-09 | MSI-4 | 本地化审校和辅助功能使用者 | 支持语言集的 UI、缩放和可访问性记录 |

没有相应环境时保留待验收，不把预测写成通过；若某项是阶段必需门槛（尤其 MSI-OI-01/03），不得以待办名义跳过并宣布阶段完成。
