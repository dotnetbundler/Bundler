# NSIS 外部验收与待输入事项

本文件只记录无法凭仓库内 fixture 如实完成的工作；本机可自动验证的实现工作不能转移到这里。前置条件、命令、预期结果、证据字段和清理步骤集中在 `docs/nsis-manual-testing.md`；本表是简短的外部输入索引。

| 事项 | 当前原因 | 所需输入或环境 | 影响与边界 |
| --- | --- | --- | --- |
| 生产 Authenticode 全链签名 | 隔离载荷、插件、卸载器、安装器及外部命令提供方已用一次性 fixture 验证；仓库没有生产证书、HSM/云账户或公共时间戳服务契约。 | 在受控发布环境提供生产签名身份/提供方和 RFC 3161 策略。 | 本机已验证顺序、隔离、PE 签名、失败清理、提供方调用和敏感信息隐藏；公开信任链、硬件/云策略、时间戳接受度及 SmartScreen 声誉仍需外部证据。 |
| 真实旧 WiX/MSI 产品迁移 | 已实现按 ProductCode/UpgradeCode 配置的迁移，但没有真实历史标识或已发布 MSI。 | 准确的旧标识，以及代表性的 x86/x64、当前用户/所有用户 MSI 或注册表导出。 | 一次性 fixture 只证明通用机制；真实已发布产品的识别和提权行为未验证。 |
| 提权 per-machine 安装/卸载与 journal ACL | 普通本机测试不得静默触发 UAC。当前用户 journal 与 HKCU 完整性锚点可由同一用户写入；本机没有由提权安装创建的 `%ProgramData%\DotNetBundler` 目录可供最终 ACL 取证。还需检查标准用户预先创建子目录时的所有权与继承，包括恢复卸载器和注册表锚点。 | 在提权 Windows CI 或 MT-01/MT-07 中记录所有者、`icacls`、HKLM 权限及预建父目录情况。 | 本机已验证载荷/注册表快照与恢复 EXE 篡改检测，尚未证明低权限攻击者不能抢先创建或替换 per-machine journal 文件；发行验收需要真实提权边界证据。 |
| 真实需要重启的文件删除 | 集成测试通过设置 NSIS 重启标志验证 `3010`、已提交状态、journal 清理和禁止重启前启动，但刻意不修改全局待重命名队列。前向卸载失败和中断恢复无需重启即可自动化。 | 在提权、可丢弃 Windows VM 执行 `tests/Windows.Nsis.Reboot/Verify.ps1`，重启后执行复核阶段。 | 脚本复制卸载器并用 `_?=` 等待真实卸载进程，而非 NSIS 自复制 launcher；要求 `3010` 和本产品拥有的延迟删除。队列实际执行及重启后清理仍需外部证据。安装时锁定文件替换故意不排队：延迟替换需要提权，无法为 `currentUser` 保证一致行为，也不能安全纳入安装回滚。见 `docs/nsis-locked-payload-policy.md`。 |
| 跨 Windows 版本的开始菜单/任务栏固定项清理 | 快捷方式所有权检查和 AppUserModelID 已实现，但固定项存储和支持的取消固定接口随系统版本、策略变化。 | 在支持的 Windows 10/11 build 上人工检查升级前和卸载前已固定的项目。 | 安装器会保留被其他程序接管的同名快捷方式；目前不保证自动取消固定。 |
| 真实 ACL 拒绝与磁盘耗尽 | 确定性故障注入覆盖事务检查点，但不等于 NTFS/注册表 ACL 拒绝或实际物理磁盘/配额耗尽。 | 按 MT-07 在可丢弃 Windows VM 中使用窄范围拒绝规则及专用虚拟磁盘或配额。 | 产品承诺安全失败与恢复，不承诺完整 ACL/ADS 元数据保真；真实系统故障仍需外部证据。 |
| 原生构建宿主与 Windows ARM64 矩阵 | 工具选择和包覆盖 Windows、Linux x64/arm64、macOS x64/arm64 宿主及 Windows x64/arm64 目标，但单台开发机不能代表全部组合。 | 按 MT-08/09 使用原生 runner 和 Windows ARM64 设备或 VM。 | 仓库测试验证选择、缓存完整性和本机 Windows x64 行为；原生执行声明只能覆盖实际测试环境。 |
| 内置语言文案审校 | 自动测试验证统一键集、编译 22 种内置语言并运行非拉丁文字 Windows 安装/卸载 fixture；新增翻译尚未由母语者或专业译者审校。 | 每种语言的母语/专业审校，附代表性缩放下的 Windows 截图；阿拉伯语、波斯语重点检查从右到左布局。 | 本机已验证结构与 Unicode 传输；语言准确性、地区术语、文字截断和 RTL 视觉质量仍是 MT-11 的外部内容验收。 |
